# Figure outputs

The manuscript uses four main Results figures:

1. Behavioural results: participation, conditional acreage and behavioural access.
2. National mobilization: experiment-anchored offers, rent-indexed compensation,
   experimental-support exposure and unmet-biomass concentration.
3. Uncertainty and evidence: statistical, structural, upstream-family and
   duration sensitivity plus feedstock evidence coverage.
4. Spatial robustness: implementation pressure, probability of binding,
   top-risk probability and cross-family hotspot consensus.

Run:

```bash
python scripts/10_make_figures.py
```

Expected exports are PDF, SVG and high-resolution PNG. The binary reporting
workbook is a plotting layer only and is not the authoritative scientific model.
